Tek Pak Desktop — Diamonds Outta Dirt
=====================================
Runs on YOUR computer only. No HostGator. No website.

WINDOWS — try these in order:
1. Double-click:  OPEN TEK PAK.html     <-- easiest, always works
2. Double-click:  Start Tek Pak.vbs
3. Double-click:  Start Tek Pak.bat

If Windows blocks a .bat/.vbs: right-click -> Properties -> Unblock -> OK
Or right-click -> Run anyway

MAC:
1. Double-click:  OPEN TEK PAK.html
2. Or: Start Tek Pak.command (right-click -> Open the first time)

Tips:
- Keep the whole tekpak-desktop folder together
- Packs save on this computer
- Use SAVE DRAFT / + REV / EXPORT PRINT
