# Tek Pak Desktop — Diamonds Outta Dirt
=====================================
Runs on YOUR computer only. No HostGator. No website.

INSTALL AS AN APP (Windows) — do this once:
1. Unzip DOWNLOAD-TekPak-Desktop-App.zip
2. Open the tekpak-desktop folder
3. Double-click:  Install Tek Pak.bat
4. That puts "Tek Pak" on your Desktop + Start Menu and opens it

NEXT TIME:
Double-click the "Tek Pak" icon on your Desktop.

IF INSTALL IS BLOCKED:
Right-click Install Tek Pak.bat -> Properties -> Unblock -> OK
Or: right-click -> Run as administrator

QUICK OPEN (no install):
Double-click:  OPEN TEK PAK.html

MAC:
Double-click OPEN TEK PAK.html
Or run Start Tek Pak.command

Tips:
- Keep files together if you use the folder without installing
- Packs save on this computer
- Use SAVE DRAFT / + REV / EXPORT PRINT
