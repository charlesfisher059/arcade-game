# Tek Pak Desktop

Runs on **your computer only**. No HostGator. No website upload.

## Windows
1. Download / unzip `tekpak-desktop`
2. Double-click **`Start Tek Pak.bat`**
3. Tek Pak opens in its own app window (Edge or Chrome)

## Mac
1. Unzip `tekpak-desktop`
2. Right-click **`Start Tek Pak.command`** → Open (first time)
3. Or double-click after allowing it in System Settings

## Or
Open `index.html` in Chrome/Edge.

## Notes
- Packs save on this computer (browser storage)
- Use **SAVE DRAFT** / **+ REV** and **EXPORT / PRINT**
- Templates: Tee, Hoodie, Pants, Shorts, Cap
